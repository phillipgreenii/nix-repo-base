# Bootstrap the workspace, then run apply.
# `workspace allow` is REQUIRED before apply: build_command and activate_command
# are config-sourced argv, so Apply is TOFU trust-gated via ensureExecTrusted
# (ADR-0019). Each scenario gets a fresh XDG_STATE_HOME, so the synthetic
# workspace is always untrusted until allowed.
workspace init
workspace clone
workspace lock
workspace allow
workspace apply
